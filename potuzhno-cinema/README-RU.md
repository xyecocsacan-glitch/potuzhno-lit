# Потужно Кино — независимый мод катсцен

Fabric Minecraft Java 1.21.11, Java 21, Fabric API.

**F8** запускает 12-секундную демонстрационную катсцену вокруг игрока с кинематографической камерой, тремя субтитрами и звуковым эффектом. **Esc** или F8 пропускает катсцену. При выходе из мира, открытии меню или потере фокуса катсцена останавливается. Работа мира/сервера не приостанавливается.

Это отдельный клиентский JAR, он не нужен на сервере и никак не модифицирует «Потужно Літ». Сцена — заготовка системы, которую можно расширять собственными скриптами и актёрами. В игре не проверено.
