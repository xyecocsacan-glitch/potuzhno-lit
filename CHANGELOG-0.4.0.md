# 0.4.0 — модели и текстуры

Minecraft Java 1.21.11, Fabric Loader 0.18.1+, Fabric API для 1.21.11.

- Дрон: отдельная чёрная рама, четыре трёхлопастных винта, синий аккумулятор с ремнями, объектив камеры, антенна и зелёный индикатор. Стилизация по предоставленному фото, а не точная копия.
- Потужно Літ: сине-жёлтый корпус-бочка с открытой кабиной, деревянным сиденьем и доской сзади, передним пропеллером, металлическими опорами и двумя пулемётами по бокам.
- Настоящие клиентские модели вместо отдельных block-display сущностей. Анимация винтов и отдельные текстурные атласы 128×128. Разные иконки 64×64.
- Удаляются только старые декоративные block-display части с UUID именно этого аппарата при загрузке существующего мира 0.3.0.
- Сохранены рецепты, предметы в креативе, FPV-камера, рамка и ТВ-помехи, дистанционный подрыв G, снижение X/стрелка вниз и стрельба самолёта.
- GeckoLib и отдельный ресурс-пак не нужны.

## Установка

Закройте игру и замените старый JAR мода в папке mods новым. Не оставляйте две версии одновременно. Fabric API оставьте. На сервере и клиенте устанавливается одна и та же версия мода. Перед обновлением сохраните резервную копию мира; для первой проверки используйте тестовый творческий мир.

## Проверка

Сборка проверяет Java-код, тесты управления и читаемость/размеры новых PNG. Эти проверки не заменяют визуальную проверку в запущенной игре.
