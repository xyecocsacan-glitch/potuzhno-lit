# Potuzhno Inventory Camera 1.0

Клиентский мод для Minecraft Java 1.21.11 Fabric. Показывает персонажа спереди в мире при открытии E/инвентаря или творческого инвентаря. После закрытия восстанавливает исходную камеру. Не меняет сервер и мир.

Для прозрачного интерфейса отдельно нужен ресурс-пак **Potuzhno Glass Inventory**. Мод не изменяет оригинальный «Потужно Літ».
