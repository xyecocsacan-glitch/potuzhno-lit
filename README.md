# Потужно Літ — Minecraft Java Edition 1.21.11

Исходный проект Fabric для двух летающих аппаратов: дрон-камикадзе и «Потужно Літ» с пулемётом.

## Возможности прототипа

- Поставьте аппарат на землю, нажав ПКМ с предметом в руке.
- Нажмите **E** рядом с аппаратом, чтобы сесть/выйти. В Minecraft E по умолчанию открывает инвентарь — переназначьте клавишу инвентаря, например, на **I**, чтобы избежать конфликта.
- **WASD** — перемещение по горизонтали, **пробел** — вверх, **X** — вниз.
- **ЛКМ** — выстрелы «Потужно Літа» по направлению взгляда, урон 4 за попадание, интервал 5 тиков.
- Дрон при столкновении с твердым блоком или сущностью взрывается (сила взрыва 3).
- Аппараты можно получить из вкладки инструментов в творческом режиме либо изготовить.

## Крафт

«Потужно Літ»:

```
[синий краситель] [жёлтый краситель] [пусто]
[железо]          [пусто]             [железо]
[железо]          [железо]            [железо]
```

Дрон-камикадзе (TNT в центре, 8 железных слитков вокруг):

```
[железо] [железо] [железо]
[железо] [  TNT  ] [железо]
[железо] [железо] [железо]
```

Оба предмета зарегистрированы в творческом инвентаре во вкладке «Инструменты и приспособления» и доступны через строку поиска.

## Сборка

Требуется **Java 21**, Gradle 9.2.1+ и интернет для загрузки Minecraft/Fabric. На ПК в папке проекта запустите:

```bash
gradle wrapper --gradle-version 9.2.1
./gradlew build
```

Windows: `gradlew.bat build`. Полученный мод будет в `build/libs/`, файл без `-sources` в названии. Положите JAR в `.minecraft/mods/` вместе с **Fabric API для 1.21.11**.

## Статус

Это **исходный прототип**, а не проверенный в игре готовый JAR. В текущем окружении нет Gradle и внешней сети, поэтому зависимости не скачаны, сборка и запуск не проверялись. Перед реальной игрой возможны правки несовпадающих API 1.21.11.

Визуальная модель пока упрощена: корпус отображается блоками синего/жёлтого бетона и железа, а не высокодетализированной моделью с фотографии. Визуальные блоки — отдельные сущности-отображения, и при аварийном завершении сервера могут остаться в мире. Для готового релиза их лучше заменить единым клиентским рендерером.

## Важные примечания

- Это **исходники**: сборка и игровой тест не выполнены в среде генерации, потому что нет Gradle и доступа к Maven. Не называйте архив готовым `.jar`.
- После генерации Gradle Wrapper используйте `gradlew.bat build` в Windows или `./gradlew build` в Linux/macOS.
- Для корректной работы клиентской части в `build.gradle` включён `splitEnvironmentSourceSets()` и объявлены `main` и `client`.
- По умолчанию E открывает инвентарь: в управлении Minecraft переназначьте инвентарь на I.
- Рецепт дрона использует 8 железных слитков и TNT по центру.
- При игре на сервере установите мод и Fabric API **и на клиенте, и на сервере**.

## Сборка без установки Gradle: GitHub Actions

Загрузите содержимое папки `minecraft_drone_mod` в репозиторий GitHub. Откройте **Actions -> Build Minecraft mod -> Run workflow**. Workflow запустит Gradle на Java 21 и опубликует JAR в артефактах, **если компиляция прошла успешно**. Если будут ошибки компиляции, смотрите лог шага `Compile mod`.
